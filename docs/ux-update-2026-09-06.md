# 交互体验更新 · 2026-09-06

本次改动在现有静态网站与 Supabase 接口上完成，无需数据库迁移。

## 使用变化

- 桌面切页同步提交，只为新页面添加短过渡；手机仅移动标题，避免大型社区信息流参与整页动画。
- 弹窗关闭与再次打开可从当前显示状态反向过渡，取消的任务不再改变新窗口状态。
- 底部导航指示器从当前位置转向新目标；侧栏等到横向拖动越过阈值才接管手势，支持纵向滚动和普通点击。
- 返回页面恢复本次访问的阅读位置；文章后台刷新保留页码，数据未变时不重绘。
- 搜索具有防抖、中文输入法处理和请求顺序保护；用户名字与文章结果可通过键盘打开。结果区独立滚动。
- 聊天按消息 ID 增量更新。上翻记录时收到消息只更新提示，点击“回到最新消息”再跳到底部。
- 私信和群聊分开保存文字草稿，并显示字数。发送中允许继续输入，旧请求不得清空新输入或另一个会话。
- 手机回车换行、点击箭头发送；电脑 Enter 发送、Shift + Enter 换行；Ctrl / Command + Enter 也可发送。
- 静态资源使用内容哈希版本，同一天多次构建不会共用一个缓存版本号。

## 草稿的隐私与边界

草稿只保存在当前标签页的 sessionStorage（不可用时退回内存），以账户和会话隔离；最多保留 20 个会话、24 小时内的文字。关闭标签页不会承诺恢复；退出登录清除草稿。没有增加云端草稿表，也不保存附件文件或引用对象。

## 构建与验证

```powershell
npm run build
npm test
```

浏览器测试需要本机 Chrome/Chromium；自定义路径可通过 `SELF_CHECK_CHROME` 环境变量指定。新用例在 `tools/ux-regressions.js`，入口为 `tools/ux-self-check.html`，已接入 `npm test`。

```powershell
$env:SELF_CHECK_THEME = 'dark'
npm test
Remove-Item Env:SELF_CHECK_THEME

$env:SELF_CHECK_REDUCED_MOTION = '1'
npm test
Remove-Item Env:SELF_CHECK_REDUCED_MOTION
```

新回归包含弹窗中途反向、连续切页、阅读位置恢复、搜索乱序、中文输入、切换会话竞态、延迟发送、失败保留输入、增量 DOM/媒体保留、阅读期间新消息提示、私信/群聊草稿和退出清理。原有登录注册、会话恢复、群聊、管理面板、移动侧栏及壁纸入口测试继续运行。

自动测试使用本地模拟 API，不写入线上用户、消息或数据库；不能替代两台真实设备之间的 Supabase Realtime 联调。手机布局测试使用 Chromium 的 390×844 视口，尚未在真实 iPhone Safari 上测试触摸、软键盘和视频播放。
